# MurrayStateCampusNavigation - Protocol

This file defines the local workflow for this repository.

This repo must remain usable on its own, without requiring `C:\GitHub` to exist.
If broader coordination context is available, `C:\GitHub\.protocol.md` is the preferred top-level entry point, but it is optional.

<!-- @always -->
## Critical rules (MurrayStateCampusNavigation)

- GAS deploy sequence: `push → create-version → deploy -i -V N`; `clasp update-deployment` (v3.2.0) is broken. `deploy.ps1` implements the correct sequence.
- `scripts/apps-script/.clasp.json` contains the script ID — treat as secret; never read or log its contents.
- Google Maps API key and ADMIN_PIN live in GAS Script Properties only — never in the repo.
- All GAS client-side JS must be ES5-compatible (var only, no arrow functions, no template literals) — Admin.html is ~4400 lines of ES5.
- Floor plan images are loaded server-side via `getFloorPlanFile(fileId)` (CORS bypass) — direct Google Drive URLs will 403 from GAS client.
- HtmlService strips HTML comments — never use HTML comments as version markers.

## During Work

- Follow `.standards.md`
- Check `.changelog.md` before overlapping work
- Keep `.project-context.md` current when state changes

## Logging

Use `.changelog.md` with this format:

```text
### [YYYY-MM-DD HH:MM] AGENT_NAME [ACTION_TYPE]
- Description of changes
- Repo: MurrayStateCampusNavigation
- Files modified: <paths from repo root>
- Notes: Important context for other agents
- Why: Why this change was made
- PENDING: (optional) Follow-up work
```

## Working Files

- Use `.scratch/` for temporary scripts, debug artifacts, and working files
- Use `.research/` for reference materials, external tools, and research
- Both directories are gitignored — do not commit their contents

## Incomplete Work

Track incomplete work in `.project-context.md`:

- `TODO` for actionable follow-up
- `Pending Decisions` for unresolved choices
