      Google Maps API Key

      Used for the campus map in the navigation app and in the Buildings tab. Without a key the app still works: it lists buildings with "Open in Google Maps" walking links. Use a browser key restricted to this web app's address (HTTP referrer restriction) and to the Maps JavaScript API.

      Saving replaces the stored key. The field is cleared after saving.

      Change Admin PIN

      6 to 20 characters, no spaces. Everyone who uses the admin page will need the new PIN.

      Where these values live

      In the Apps Script editor, open Project Settings and scroll to Script Properties: mapsApiKey holds the Maps key and ADMIN_PIN holds the PIN.

      A new deployment generates a random PIN the first time it is initialized; the project owner reads it there. If the PIN is forgotten, the project owner can read or replace ADMIN_PIN in the same place.
