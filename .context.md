## Architecture

GAS web app (HtmlService) with 4 tabs (Map, Indoor, Schedule, Scan) + standalone admin page at `?action=admin`. Data: Google Sheets (8 tabs: Config, Buildings, Floors, Rooms, NavNodes, NavEdges, Photos, QRLocations). Backend JS: Code.gs (router), API.gs (data access), Init.gs (sheet setup + seed), AdminAPI.gs (CRUD, 20 functions), SeedData.gs (89 buildings + EP/IT floors/rooms). Mobile-first, localStorage caching with version-check, offline fallback. (source: .changelog.md 2026-02-19 design/implementation entries)

## Critical gotchas

- `clasp update-deployment` v3.2.0 is silently broken; use `push → create-version → deploy -i -V N`. (source: .changelog.md 2026-02-19 12:00)
- GAS HtmlService strips HTML comments — never use HTML comments as version markers. (source: .changelog.md 2026-02-19 06:30)
- Pannellum viewer must be `.destroy()`-ed on close/reopen to prevent WebGL context leaks. (source: .changelog.md 2026-02-19 19:15)
- Google Maps API key is in the Config sheet + Script Properties, NOT in the repo. (source: .changelog.md 2026-02-19 12:00)
- Floor plan images load via server-side Drive fetch (CORS bypass) — direct Google Drive URLs will 403 from GAS client. (source: .changelog.md 2026-02-20 10:00)
