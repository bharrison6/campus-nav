      Doors & Hallways

      Click a door or an entrance to make it a main, alt (side) or emergency door. Click a room to make it a hallway and set the hallway's class. Routes prefer main, use alt when they must, and never pass an emergency door or hallway. A save that would leave a room or building with no route is refused.

      Doors: main alt emergency (entrances are drawn larger, with a ring) · hallways: main alt emergency · suggested hallway

      Where your edits go

      This admin runs only on your computer (npm run admin). Every save is written at once to the overrides files in data/overrides/, which hold only what you changed on top of the campus seed and the floor plans generated from the drawings. To publish: review the changes (git diff data/overrides), commit, and push; the site rebuilds itself.

      Reload from disk

      Starts the data again from the files: the seed and the generated floor data in tools/admin/gs and the overrides in data/overrides. Use it after npm run pipeline (new drawings), a git pull, or editing an overrides file by hand. Nothing saved is lost: saves are already on disk.

      Site settings

      Analytics and the site address are build settings, not admin settings: they live in build.config.json. The campus map needs no key. There is no admin PIN: this page is never published.
